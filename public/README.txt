Kohl Real Estate - Logo Package / حزمة شعار كحل العقارية
============================================================

Files included:

1. Kohl-Logo-Original.png
   As-uploaded original file, white background. Reference/master copy.

2. Kohl-Logo-White-Background.png
   Same design, flattened on a clean pure-white background (RGB, no alpha).
   Use for: white letterhead, white product backgrounds, printing.

3. Kohl-Logo-Transparent-Background.png
   Background removed, transparent PNG. This is the main file to hand to
   the marketing company for general use (place on any color background,
   website headers, social media, presentations).

4. Kohl-Logo-Transparent-Background@2x.png
   Same transparent-background file, upscaled 2x (1016x348px) for larger
   placements. Note: source artwork is a raster (not vector), so this is
   an upscale, not additional real detail. For very large prints
   (billboards, large banners), request/recreate a true vector (AI/EPS/SVG)
   version.

5. Kohl-Logo-Watermark.png
   Transparent background, ~18% opacity - ready to overlay as a watermark
   on property photos, PDFs, and videos.

Notes:
- No part of the logo design (shape, colors, text) was altered in any file
  - only background and opacity treatments were applied.
- Official brand green: #2F6D3A (primary) / #1F4D28 (dark).
- Original source: 508x174px PNG (as provided in the project).
