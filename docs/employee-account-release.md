# Employee login release — 5 October 2026

Active private Admin and CEO accounts can now create employee email/password logins from Users & Access. Add a new staff member on Employees first, then choose Create user, select Employee, select their active employee record, and set the login email and password (12–128 characters). Share the password privately. Email invitations are not required.

The private account stores the employee record ID and the EMPLOYEE role. Existing employee row policies restrict their HR records to that ID. HR `system_role` and editable Auth metadata never grant executive privileges. Employee links cannot be reassigned; duplicate, missing and terminated employee links are rejected. Only active private Admin/CEO profiles can administer accounts. Passwords are Auth-only and absent from private profiles, audit payloads and API responses.

Verified: local TypeScript and route validation/privacy checks; VPS production build; real isolated Auth/Next tests for employee creation by both Admin and CEO, password login, private employee mapping, own-record HR reads, denied user administration, immediate deactivation, failed-identity cleanup, duplicate/inactive/missing links, and regression checks for Owner/Tenant/Broker accounts.
